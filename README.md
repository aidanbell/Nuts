# Nuts

Incremental / idle game about squirrels, nuts, jobsites, and eras.

## Stack

- SolidJS + TypeScript + Vite
- Tailwind CSS v4

## Requirements

- Node.js **22.13+** (24 recommended)
- **pnpm** (via Corepack: `corepack enable`)

## Run

```bash
pnpm install
pnpm dev
```

```bash
pnpm build
pnpm lint
pnpm typecheck
```
